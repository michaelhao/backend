grade-management Specification

版本 CRU、權重排序與唯一性、狀態切換及停用後引用規則的完整行為規格
威脅模型：內部後台、非公網暴露；能登入後台者即為受信任的內部人員。版本不支援刪除——生命週期終結以停用（status）表達，確保 shop / bill / addon 的參照穩定性。
來源：openspec/specs/grade-management/spec.md 實作：934c2c1、9129b44、16890c1、e92d71f change：2026-06-12-retrofit-grades-spec
本頁為人工同步的閱讀版；若與 spec.md 不一致，以 spec.md 為準。每個 Scenario 右側標註對應的自動化測試。

版本 CRU

R1版本列表

系統 SHALL 在 GET /grades（需 Grade.index 權限）顯示所有版本，依 weight 降序排列（數值越高等級越高），每筆 SHALL 含代碼、名稱、權重、價格與狀態。
有權限者可見版本列表GradeCruTest::admin_can_access_grade_index
GIVEN持有 Grade.index 權限的使用者
WHENGET /grades
THEN系統回應 200 並渲染版本列表
依權重降序排列GradeCruTest::index_lists_grades_by_weight_descending
GIVEN權重分別為 10、90、50 的三個版本
WHENGET /grades
THEN列表依 90、50、10 的順序呈現

R2新增版本

POST /grades（需 Grade.create 權限）SHALL 以 GradeRequest 驗證：code 與 name 必填、最長 30 字元、僅限中英數與底線（regex）、各自於 grades 表內唯一；price 必填整數且不可小於 2；weight 必填整數、不可小於 1 且唯一（DB 層另有 unique index 防繞過，欄位無 default 值）；status 必填且須為 GradeStatus enum（1=啟用、0=關閉）。成功 SHALL 302 導向 /grades 並帶 success flash「版本已建立」。
成功建立版本GradeCruTest::admin_can_create_grade
GIVEN持有 Grade.create 權限的使用者
WHENPOST /grades 帶合法的 code、name、price、weight、status
THEN系統回應 302 導向 /grades 並帶 success flash
AND版本已存在於資料庫
code 重複GradeCruTest::store_fails_with_duplicate_code
GIVEN已存在 code 相同的版本
WHENPOST /grades 帶重複 code
THENsession errors 包含 code
name 重複GradeCruTest::store_fails_with_duplicate_name
GIVEN已存在 name 相同的版本
WHENPOST /grades 帶重複 name
THENsession errors 包含 name
weight 重複GradeCruTest::store_fails_with_duplicate_weight
GIVEN已存在 weight 相同的版本
WHENPOST /grades 帶重複 weight
THENsession errors 包含 weight
code 或 name 含特殊字元GradeCruTest::store_fails_with_invalid_code_characters / invalid_name_characters
WHENPOST /grades 的 code 或 name 含 !@# 等中英數與底線以外的字元
THENsession errors 包含對應欄位
price 低於下限GradeCruTest::store_fails_with_price_too_low / negative_price
WHENPOST /grades 帶 price=1 或負數
THENsession errors 包含 price
weight 缺失或低於 1GradeCruTest::store_fails_without_weight / weight_zero
WHENPOST /grades 未帶 weight，或帶 weight=0
THENsession errors 包含 weight
status 非法值GradeCruTest::store_fails_with_invalid_status
WHENPOST /grades 帶 status=99
THENsession errors 包含 status

R3編輯版本

GET /grades/{id}/edit 與 PUT /grades/{id}（皆需 Grade.update 權限）SHALL 提供版本編輯，編輯表單 SHALL 預填既有值。驗證規則同新增（code / name / weight 的 unique 排除自身）。id 不存在時 SHALL 302 導向 /grades 並帶 error flash「找不到該版本」。
redirect-with-flash UX，刻意不採 route model binding 的 404（源自 spec/7 設計）。錯誤文案原為「找不到該方案」，2026-06-12 設計 review 統一為「找不到該版本」。
成功更新版本GradeCruTest::admin_can_edit_grade
GIVEN持有 Grade.update 權限的使用者與既有版本
WHENPUT /grades/{id} 帶合法欄位（含 status 變更）
THEN系統回應 302 導向 /grades
AND版本資料已更新
編輯表單預填既有值GradeCruTest::edit_form_loads_with_existing_values
GIVEN既有版本
WHENGET /grades/{id}/edit
THEN系統回應 200，表單含該版本的 code、name、price
unique 驗證排除自身GradeCruTest::update_allows_same_code_and_name_for_self / same_weight_for_self
GIVEN既有版本
WHENPUT /grades/{id} 帶與自身相同的 code、name、weight
THEN驗證通過，無 session errors
編輯不存在的版本GradeCruTest::edit_nonexistent_grade_redirects_with_error
WHENGET /grades/99999/edit
THEN系統回應 302 導向 /grades
ANDsession 含 error flash「找不到該版本」
更新不存在的版本GradeCruTest::update_nonexistent_grade_redirects_with_error
WHENPUT /grades/99999 帶合法欄位
THEN系統回應 302 導向 /grades
ANDsession 含 error flash「找不到該版本」

權重系統

weight 決定等級高低（數值越高等級越高）；唯一性三層保證——FormRequest unique 規則、check-weight 即時檢查（UX）、DB unique index（防繞過）。

R5權重即時檢查端點

GET /grades/check-weight（需 Grade.update 權限，供新增/編輯表單即時驗證與位置預覽）SHALL 回應 JSON：duplicate（該 weight 是否已被使用）、conflicting_grade（衝突版本的 id / name / weight，無衝突為 null）、grades（全部版本的 id / name / weight，依 weight 降序）。帶 exclude_id 時 SHALL 豁免該 id 自身；weight 小於 1 時 SHALL 直接回應 duplicate=false、grades=[]，不查詢資料庫。
權重已被使用GradeCruTest::check_weight_returns_duplicate_for_taken_weight
GIVEN已存在 weight=77 的版本
WHENGET /grades/check-weight?weight=77
THEN回應 duplicate=true 且 conflicting_grade 為該版本
權重未被使用GradeCruTest::check_weight_returns_no_duplicate_for_unused_weight
GIVEN已存在 weight=77 的版本
WHENGET /grades/check-weight?weight=78
THEN回應 duplicate=false、conflicting_grade=null，grades 含既有版本
exclude_id 豁免自身GradeCruTest::check_weight_excludes_self_with_exclude_id
GIVENweight=77 的版本
WHENGET /grades/check-weight?weight=77&exclude_id={自身 id}
THEN回應 duplicate=false
weight 低於 1 回空結果GradeCruTest::check_weight_below_one_returns_empty
WHENGET /grades/check-weight?weight=0
THEN回應 duplicate=false、conflicting_grade=null、grades=[]
無權限者被擋GradeCruTest::viewer_cannot_check_weight
GIVENViewer 角色（無 Grade.update）
WHENGET /grades/check-weight?weight=77
THEN系統回應 302（導向 default_route）

狀態切換與停用

停用＝「不再賣這個版本」：只擋新指派、保留既有引用，否則管理員僅修改其他欄位也會被驗證擋住。

R4狀態切換

PATCH /grades/{id}/toggle（需 Grade.update 權限，前端以 axios + 確認 modal 呼叫）SHALL 回應 JSON：成功時切換 status（Active ↔ Inactive）並回應 200 與訊息「版本狀態已更新」；id 不存在時回應 422 與訊息「找不到該版本」。
舊 spec/5 原設計為 form POST + redirect flash，後續比照 spec/10 的 axios + 自訂 modal 模式改版，免整頁 reload。
啟用版本切換為關閉GradeCruTest::admin_can_toggle_active_grade_to_inactive
GIVEN啟用中的版本
WHENPATCH /grades/{id}/toggle
THEN系統回應 200，版本 status 變為 Inactive
關閉版本切換為啟用GradeCruTest::admin_can_toggle_inactive_grade_to_active
GIVEN關閉中的版本
WHENPATCH /grades/{id}/toggle
THEN系統回應 200，版本 status 變為 Active
切換不存在的版本GradeCruTest::toggle_nonexistent_grade_returns_422
WHENPATCH /grades/99999/toggle
THEN系統回應 422 JSON「找不到該版本」
無權限者不可切換GradeCruTest::viewer_cannot_toggle_grade_status
GIVENViewer 角色（無 Grade.update）
WHENPATCH /grades/{id}/toggle
THEN系統回應 302（導向 default_route）
AND版本 status 不變

R6停用版本引用規則

停用版本 MUST NOT 影響既有引用：已關聯該版本的 shop / bill detail / addon SHALL 維持原樣，不被回頭驗證或自動清空。新建立的引用 SHALL 被擋下，豁免邊界依功能而異：ShopUpdateRequest 變更為停用版本 → 422，維持原版本（即使已停用）→ 允許；StoreBillRequest 任何停用版本 → 422，無豁免；AddonRequest 新關聯停用版本 → 422，既有關聯保留 → 允許。
Shop 變更為停用版本被拒ShopRuTest::update_fails_when_assigning_inactive_grade
GIVEN一個停用版本
WHENPUT /shops/{id} 將 grade_id 變更為該版本
THENsession errors 包含 grade_id
Shop 維持原（已停用）版本允許ShopRuTest::update_allows_keeping_existing_inactive_grade
GIVENshop 既有版本已被停用
WHENPUT /shops/{id} 維持原 grade_id 並修改其他欄位
THEN驗證通過，更新成功
新 Bill 使用停用版本被拒BillStoreTest::store_fails_when_detail_grade_id_is_inactive
GIVEN一個停用版本
WHENPOST bill 的 details.*.grade_id 含該版本
THEN驗證失敗，bill 未建立
Addon 新關聯停用版本被拒、既有關聯保留允許AddonCrudTest::store_fails_when_grade_ids_contains_inactive_grade / update_allows_keeping_existing_inactive_grade_link
GIVEN一個停用版本
WHENaddon 的 grade_ids 新增該版本 → 驗證失敗；addon 既有關聯的版本後來被停用，更新時保留該關聯 → 驗證通過
THEN僅新指派被擋，既有關聯不受影響

UI 與 Seeder

R7UI 權限顯示控制

版本列表 SHALL 依登入者權限控制操作入口：「新增版本」以 <x-permission name="Grade.create">、「編輯」以 <x-permission name="Grade.update"> 包裹；狀態切換鈕以 hasPermissionTo('Grade.update') 判斷——有權限渲染可點擊 toggle switch，無權限渲染純狀態 badge。無 Grade.create 權限者存取 GET /grades/create SHALL 被 302 導向其 default_route。
<x-permission> 無 else slot，toggle 鈕需無權限時的 badge fallback，故用 @if hasPermissionTo——此為顯示替代內容的刻意作法，非規範疏漏。
Viewer 不可存取新增頁GradeCruTest::viewer_cannot_access_create_page
GIVENViewer 角色（僅 index 權限）
WHENGET /grades/create
THEN系統回應 302（導向 default_route）
無權限者見純狀態 badge無直接測試 — 目視確認 grades/index.blade.php
GIVENViewer 角色檢視版本列表
WHEN渲染狀態欄
THEN顯示不可點擊的狀態 badge，不渲染 toggle switch 與「新增」「編輯」入口（視圖層行為，由 blade template 保證）

R8預設版本 Seeder

GradeSeeder SHALL 以 code 為唯一鍵 updateOrCreate 建立 6 個預設版本（版本S grade_s 10000/100、版本A grade_a 9000/85、版本B grade_b 8000/70、版本C grade_c 7000/55、版本D grade_d 6000/40、版本E grade_e 5000/25，皆為啟用），並 SHALL 可重複執行（冪等）。
重複執行 seeder 收斂無直接測試 — updateOrCreate 冪等（同 PermissionSeeder 模式）
GIVEN已執行過 seeder 的資料庫
WHEN再次執行 GradeSeeder
THEN版本不重複建立，name / price / weight 被重新同步為預設值

刻意設計（不是缺漏）

以下為刻意排除的功能，避免後人誤判為待補項目。

R9無刪除功能（刻意設計）

系統 MUST NOT 提供版本刪除：無 DELETE /grades/{id} 路由、Controller 無 destroy 方法、權限模組 MUST NOT 包含 Grade.delete action（PermissionSeeder 的 Grade 模組僅 index / create / update）。此為刻意設計：版本被 shop / bill detail / addon 引用，刪除會破壞參照穩定性（spec/5 原始決策）；生命週期終結以停用（status=Inactive）表達。
DELETE 路由不存在GradeCruTest::delete_route_does_not_exist
GIVENAdmin 使用者與既有版本
WHENDELETE /grades/{id}
THEN系統回應 405 Method Not Allowed

—刻意不做的事（彙整）

刪除版本shop / bill / addon 引用的參照穩定性；以停用（status）表達生命週期終結（R9）
Grade.delete 權限PermissionSeeder 的 Grade 模組僅 index / create / update（R9）
回頭驗證既有引用停用不清空、不重驗既有 shop / bill / addon 引用，否則改個名稱也會被擋（R6）
Route model binding保留 {id} + redirect-with-flash UX，找不到版本回列表頁而非 404（R3/R4）
check-weight race 防護即時檢查與送出間的 TOCTOU 由 FormRequest unique + DB unique index 兜底（R2/R5）
x-permission else slottoggle 鈕的 badge fallback 用 @if hasPermissionTo，component 不擴充（R7）
